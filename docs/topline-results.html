Research Summary

Selected Explicit Strong Shift Equivalence Results

Given two nonnegative integer matrices, one asks whether they define conjugate shifts of finite type and, more concretely, whether they are connected by a short chain of elementary strong shift equivalences. The cases below record explicit positive examples that have become useful reference points in recent work: the A_k, B_k 2×2 family highlighted by Brix and Ruiz, the explicit lag-7 witness recorded by Baker and reproduced in Lind and Marcus, and a large-lag family discussed by Boyle and Schmieding.

Several explicit lag-7 witnesses are available for the k = 3 member of the A_k, B_k family

For the k = 3 member of the A_k = [[1,k],[k-1,1]], B_k = [[1,(k-1)k],[1,1]] family, there are several distinct explicit lag-7 strong shift equivalences between the prescribed endpoints [[1,3],[2,1]] and [[1,6],[1,1]]. In particular, the computed lag-7 witnesses include paths whose first nontrivial matrices differ from the classical Baker witness recorded in Lind and Marcus, Example 7.3.12. The four explicit paths are listed in the Appendix.

Sources: Brix-Ruiz (2025), Example 3.8, Lind-Marcus (2021), Example 7.3.12, and Baker (1983), with further details in a GitHub note documenting the non-Baker lag-7 witnesses for k = 3. 

cargo run --quiet --bin search -- \
  1,3,2,1 1,6,1,1 \
  --stage endpoint-search \
  --frontier-mode bfs \
  --move-policy graph-plus-structured \
  --max-lag 8 \
  --max-intermediate-dim 4 \
  --max-entry 5 \
  --endpoint-multi-meet-cap 12 \
  --json

In the current public repository state, this returns 4 witness paths, each with path_lag = 7.

The four lag-7 witnesses remain distinct under a conservative internal identification test

These lag-7 witnesses are not merely relabelings of the Baker path. The comparison used here is intentionally stronger than a raw comparison of matrix lists: each intermediate matrix is first replaced by a canonical representative up to permutation of vertices, and then short local substitutions are allowed inside a path. The test allows two kinds of local simplification:

  • a triangle collapse, replacing a two-step subpath A → B → C by the direct step A → C when that direct step already appears elsewhere in the witness corpus;
  • a commuting-square normalization, choosing one preferred representative among two different two-step subpaths with the same endpoints.

This “path quotient” is not a standard literature notion; it is a deliberately conservative project-internal test for whether two computed witnesses should be regarded as the same after simple endpoint-preserving local simplifications. Under this test, the four lag-7 witnesses still represent four separate classes. When the Baker witness is added to the same comparison, the result is still five separate classes.

Sources: code for the analysis in analyze_guide_pool_quotient.rs, together with the comparison code in path_quotient.rs, and the stored witness paths for the Baker witness and the four computed exact-endpoint lag-7 paths. 

cargo run --quiet --features research-tools \
  --bin analyze_guide_pool_quotient -- \
  --guide-artifacts research/guide_artifacts/k3_exact_endpoint_multi_meet_retained_pool_2026-04-19.json \
  --json-out tmp/k3_exact_meet_retained_pool_quotient.json

In the current public repository state, the four computed witnesses remain four separate classes under this test. Adding the Baker witness yields five classes, not one.

A bounded search also finds a graph-move-only witness for the same k = 3 pair

The same endpoint pair also admits a witness using only graph presentation moves, namely state splittings and state amalgamations. A direct search at dimension bound 5 and entry bound 6 finds such a witness.

Here a state split is a Williams graph move that replaces one vertex by a small family of vertices carrying a partition of its incoming or outgoing edges, while a state amalgamation is the inverse merge. These are the classical graph-presentation moves underlying strong shift equivalence for edge shifts.

A companion run that retains multiple exact meetings at the prescribed endpoints produces two distinct graph-move-only witnesses at the same bounds; these also remain distinct under the same internal identification test used above. Both paths are listed in the Appendix.

Sources: Williams (1973), together with the hard positive family in Brix-Ruiz (2025), Example 3.8. 

cargo run --quiet --bin search -- \
  1,3,2,1 1,6,1,1 \
  --max-lag 22 \
  --max-intermediate-dim 5 \
  --max-entry 6 \
  --move-policy graph-only \
  --json

In the current public repository state, this returns a graph-move witness of lag 17.

A size-2 example from a large-lag family of Boyle and Schmieding is solved directly at k = 14

Consider the family A_k = [[k,2],[1,k]] and B_k = [[k-1,1],[1,k+1]], discussed by Boyle and Schmieding as a source of large-lag examples. For the case k = 14, the endpoint pair [[14,2],[1,14]] and [[13,1],[1,15]] is solved directly by bounded search.

The successful search uses the classical graph moves together with explicit elementary nonnegative matrix factorizations. In the computations recorded in the linked note, the even cases k = 4, 6, 8, 10, 12, 14 all behave similarly, and the command below reproduces the largest of those cases.

Sources: Boyle-Schmieding (2023), Riedel example, with a GitHub note tabulating the cases k = 4, 6, 8, 10, 12, 14. 

cargo run --quiet --bin search -- \
  14,2,1,14 13,1,1,15 \
  --max-lag 14 \
  --max-intermediate-dim 3 \
  --max-entry 14 \
  --move-policy graph-plus-structured \
  --json

In the current public repository state, this returns a witness of 15 matrices.
